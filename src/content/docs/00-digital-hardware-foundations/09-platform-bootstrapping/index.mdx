# 09. Platform Bootstrapping Architecture

This course covers initial hardware bring-up from Power-On Reset (POR) through Root of Trust verification, Cache-as-RAM staging, DRAM PHY training, multi-core SMP parking/wakeup, PCIe enumeration, and kernel handoff contracts.
