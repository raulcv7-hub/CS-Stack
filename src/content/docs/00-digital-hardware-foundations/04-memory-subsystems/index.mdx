# 04. Memory Subsystems Architecture

This course covers the memory hierarchy, detailing SRAM cache cell mechanics, set-associativity, TLB translation, non-blocking MSHRs, hardware memory consistency (TSO), MESI/MOESI cache coherence, and DRAM controller scheduling.
