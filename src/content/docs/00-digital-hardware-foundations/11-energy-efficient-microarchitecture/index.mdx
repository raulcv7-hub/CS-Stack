# 11. Energy-Efficient Microarchitecture

This course covers low-power microarchitectural design, detailing dynamic and static CMOS power mechanics, integrated clock gating, state retention power gating, DVFS controllers, processor C/P states, and IEEE 1801 (UPF) power intent.
